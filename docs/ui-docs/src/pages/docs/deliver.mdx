# Deliver

## Internal build and run

Once you’ve created your graph, you should test it before launching to the web. To do this, enter “Deliver“ section of the app by pressing the corresponding button in the bottom bar.

The section consists of five main columns:

1. ‘New build’ lets you set up a build of your bot. Enter the build name, select a messenger interface and a build preset - a set of rules that will apply to this build. Then press the ‘Build‘ button.
2. ‘Existing builds’ shows a list of your previous builds and the queue of currently processing builds. You can click on an item to see the selected build’s details. An icon on the right hand side represents the status of the build: a green checkmark means that the build has completed successfully, and a red cross means that something went wrong in the process. You can rebuild any of them if the dialogue graph has changed and your preferences for build options have not.
3. ‘New run’ lets you configure a run for a successful build. Enter a name for this run, select a build and a run preset, then press the ‘Run‘ button.
4. ‘Running‘ column shows all the runs that are active right now. You can create different runs for different builds at the same time and compare their performances.
5. ‘Previous runs‘ shows all the runs that have been stopped. All the failed runs will appear in the corresponding section, and both failed and previous runs can be queued for a rerun with an circle arrows button on the right hand side.

### Quick build & run

If you don’t want to spend time configuring build and run, you can press ‘Quick build & run‘ button to get the job done automatically. The same set of information will appear once it is complete.

### Test panel

You can also access the test panel to run some additional processes, such as tests and auxiliary runs.

## Launch to Telegram

As versatile as the internal delivery system is, the point of Chatsky UI is to launch your bots to messengers of your choice.

To do this:

1. Select a preferred messenger in the Build settings and press 'Build'
2. Select the new build in the Run settings, then enter an API token for the selected messenger
3. Press 'Run', then the bot will be live until you stop the run.

## Version history

It is recommended to save your graph to version history once in a while. To do this, press the clock icon in the top bar to access history panel. Then enter this version’s name and press ‘Save‘.

To load a saved version, open the history panel, select an item and press ‘Restore‘. This will delete your current dialogue graph, so don’t forget to also save it.
