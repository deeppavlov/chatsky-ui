
# Slots

Slots are a tool that helps you make your bot feel more personal. They let you configure which pieces of information the bot can remember and use in the dialogue later. For example, if a user enters their name during a conversation, the bot can remember it and say it when it is appropriate.

The tutorial below explain what kinds of slots are available in Chatsky UI and how to configure them.

## Slot types

Slots are essentially pieces of text that can be extracted and then placed into bot's responses. There are two extraction methods:

1. LLM prompt - enter a prompt describing what piece of information this slot has to remember
2. Regular expression - if the text you would like to extract is unique to this message, enter a regexp structure describing that text

## Slots node

Slots in Chatsky UI are stored and created in slots nodes. You can find this component in the sidebar alongside default node.

### Slot group

After dragging a slots node to the canvas, you can create a slot group inside it. A group unites several slots based on any attribute you like. For example, user's name and their age will go perfectly in 'Personal info' group. After creating a group, you can create individual slots inside it using methods discussed above.

You can access every group by pressing arrow button next to it. Here you can configure all the slots inside the group and set, whether this group is standalone or a subgroup of another one. Subgroups are rendered inside their parent groups in the slots node.

### Slots node settings

Nodes settings are a modal window that you can access by pressing a 'Settings' button on the slots node. This window shows the node's description and all the groups inside it. Here you can create new groups reorder them by dragging three lines on the left hand side in the table.
