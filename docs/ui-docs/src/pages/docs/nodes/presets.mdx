
# Presets

If you have a configuration of several nodes that you would like to use multiple times in your projects, you can create presets and drag them onto canvas just like any other component.

1. Select every node you need by dragging left mouse button across the canvas or by clicking on every node while pressing Shift key
2. Click on the jigsaw icon in the top bar, and 'New preset' modal window will appear
3. Enter preset name, select a display color and click 'Create'
4. Your preset will be stored in the 'Presets' section of the sidebar

Presets save nodes with everything you have configured inside previously. You can access and review your presets in the [according Library section](http://).
