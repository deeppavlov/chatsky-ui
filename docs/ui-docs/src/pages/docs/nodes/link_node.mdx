
# Link

After connecting every node within a flow, you should place transitions across between all other flows. To do this, use link - a node-like structure that executes the same transition as an arrow but across two flows.

In the first flow, select ‘Link’ in the sidebar and drag it onto the canvas. A modal window will show up automatically. Select a flow, to which you would like to transition, and a node - the destination point. After that, connect any node to the link with an arrow. Now, the arrow-connected node is the "from" and the node you have selected in the window is the "to".

## List of incoming links

If you go to the second flow, the "to" node now has an indicator showing incoming links. You can click on it and review all the transitions from different flows.
