# Inspect (99%)

Inspect section of the app allows you to troubleshoot any issue with your bot. This is the place where you can test the bot in action by chatting with it and inspect all its builds and runs’ logs.

## Logs

Every action you take in ‘Deliver’ section is recorded in logs under a corresponding name. You can select a build, a run or a test you have conducted and see if they were successful, and if not, what went wrong.

### Build logs

Build logs page consists of build’s status, completion time, duration, chosen preset and logs themself which you can inspect in Chatsky UI or export by clicking a link.

## Chat preview

Chat window in Chatsky UI imitates your preferred messenger interface and changes its functionality depending on what interface you have chosen for every particular build.

### Select chat

After you have built and run your bot, expand the chat window by pressing `<<` button, then click `New chat` and select a build and a run, then you can chat with it.

Chat history is saved in the panel’s sidebar, so you can test several chats all at once.

### Refresh dialog

If you want to start over and chat with your bot from the beginning, simply press the ‘Refresh‘ button.

### Select messenger interface

If you have used `Quick build and run` option or have not specified any messenger interface, your build will be suitable for all of them. To test your bot in different interfaces, select one in the top bar of the chat window.

### More options

Pressing three dots at the top right corner of the chat window reveals two more options for chat management:

- Export dialog history to share it with your team members or for a future Chatsky UI project
- Restore an old build version if you like that chat best
